# 玄匣 Vaultory

安全、轻量的本地密码管理桌面应用，基于 Tauri + React + Rust 构建。

## 版本说明

当前仓库为本地版：纯本地存储，数据保存在本地 SQLite 数据库，无需网络。

## 功能特性

- 🔐 **主密码保护** - Argon2id 密钥派生 + AES-256-GCM 加密
- 📁 **文件夹管理** - 支持多级嵌套文件夹分类
- 🔍 **智能搜索** - 快速搜索名称、用户名、网址、API Key
- 🎲 **密码生成器** - 可配置长度、字符类型、排除易混淆字符
- 👤 **用户名生成器** - 生成随机用户名
- 🌙 **深色模式** - 一键切换明暗主题
- 🌐 **多语言** - 支持中文/英文界面
- ⏱️ **自动锁定** - 可配置空闲自动锁定时间
- ⭐ **收藏标记** - 快速访问重要条目

## 安全特性

- ✅ AES-256-GCM 认证加密
- ✅ Argon2id 密钥派生（抗暴力破解）
- ✅ 分离的哈希/加密 Salt（防彩虹表攻击）
- ✅ 内存密钥自动清零（防内存转储攻击）
- ✅ 数据库事务保证操作原子性
- ✅ 敏感错误信息不泄露

## 快速开始

### 直接使用

运行发布包中的可执行文件即可启动。

首次启动需要设置主密码，请妥善保管，**丢失后无法恢复数据**。

### 从源码构建

```bash
# 安装依赖
npm install

# 开发模式
npm run tauri dev

# 构建发布版本
npm run tauri build
```

构建产物位于 `src-tauri/target/release/` 目录。

## 技术栈

- **前端**: React 18 + TypeScript + Vite
- **后端**: Rust + Tauri 2
- **数据库**: SQLite (rusqlite)
- **加密**: AES-256-GCM + Argon2id

## 数据库结构

- `vault_entries` - 加密的密码条目
- `folders` - 文件夹分类（支持嵌套）
- `settings` - 应用设置
- `auth` - 认证信息（密码哈希 + Salt）

## 数据库迁移

首次运行新版本时会自动迁移旧数据库。如果遇到问题，可删除 `%APPDATA%\com.password-manager.app\vault.db` 重新创建（**会丢失数据**）。
